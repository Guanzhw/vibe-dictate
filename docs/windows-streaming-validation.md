# 本机验证记录 · 2026-09-11

当前安装入口：桌面和开始菜单的 **VibeVoice 语音输入**。按住 **F8** 说话时显示红点、录音计时和流式文字浮窗，松开后将最终文字输入当前窗口；托盘菜单 **Quit** 退出并停止该启动器拥有的模型服务。

客户端来自此 checkout，安装于 `%LOCALAPPDATA%\Programs\VibeVoice Dictation`。本次浮窗更新并重启后，源码和安装版 EXE 的 SHA256 均为 `181833E5F47585AC1C505A4B8AEE04B31696DE878BD739E8B464A8AC28ED43ED`；客户端 PID 为 `32052`，模型健康检查返回 `status: ok`、`device: cuda`。

后端使用 `microsoft/VibeVoice-ASR-Streaming-1.5B`，官方代码固定在 `1541f590c7099820f10ea012f48d2399282df69f`。运行环境为 Ubuntu WSL2、PyTorch 2.8.0+cu128、Transformers 4.51.3、RTX 5070 12 GB，CUDA bf16 / SDPA。音频为 24 kHz 单声道；模型每块约 2.933 秒，包含前视的首个窗口约 3.467 秒。短句在松开时补齐窗口并推理。

以下是 Windows SAPI 生成的样例，以每 50 毫秒一帧模拟实时输入，经安装版 Rust 客户端连接真实 GPU 模型。计时为单次本机观测，并非识别准确率或延迟基准。

| 样例 | 第一段结果 | 松开至最终结果 |
| --- | ---: | ---: |
| 中文极短句，约 1.36 秒 | 1.886 秒 | 0.473 秒 |
| 中文长句，约 17.8 秒 | 3.833 秒 | 0.297 秒 |
| 英文句子，约 10.36 秒 | 3.934 秒 | 0.133 秒 |
| 记事本中文输入，约 3.93 秒 | 4.099 秒 | 0.216 秒 |

浮窗更新后的中文长句复测（`feedback-live-verified.json`）：首段结果 3.836 秒，总时长 18.236 秒，发送结束信号至最终结果 0.269 秒。文字在音频仍在发送时已经显示。首段需要模型积累约 3.47 秒的音频，因此极短句仍可能在松开后才出现文字；红色录音提示不依赖模型结果。

样例中仍有模型识别误差，例如英文 `hotkey` 被识别为 `heart`。自动化分别验证了真实麦克风采集、流式传输、实际浮窗渲染和窗口注入；用户也已现场确认 F8 按住期间预览可见并更新。浮层通过 Win32 非激活样式及独立窗口线程实现，按当前前台窗口所在显示器和 DPI 定位，并完成独立源码审阅。

原始样例、JSON 结果和构建日志位于被 Git 忽略的 `target/streaming-smoke/`，作为本地验证材料保留。
